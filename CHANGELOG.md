## [2.0.0] - 2026-11-14

Native Swift rewrite of the former Python app (1.x).

Native herschrijving in Swift van de vroegere Python-app (1.x).
Native Neufassung der früheren Python-App (1.x) in Swift.

### Added / Ajouté / Toegevoegd / Hinzugefügt
- Mouse patterns: four built-in (*Classic*, *Discreet*, *Circle*, *Zigzag*) and your own,
  drawn point by point in an editor or captured from a real gesture; always the same, random or in turn.
  Motifs de souris : quatre intégrés et les tiens, dessinés dans un éditeur ou capturés d'un vrai geste.
  Muispatronen: vier ingebouwde en je eigen, getekend in een editor of opgenomen van een echt gebaar.
  Mausmuster: vier integrierte und eigene, im Editor gezeichnet oder aus einer echten Geste aufgezeichnet.
- Display choice and multi-display support / Choix de l'écran, multi-écrans /
  Schermkeuze, meerdere schermen / Bildschirmwahl, mehrere Bildschirme.
- Shortcuts actions / Actions Raccourcis / Acties voor Opdrachten / Aktionen für Kurzbefehle.
- Interface in English, French, Dutch and German, following the macOS language; *Language* menu.
  Interface en anglais, français, néerlandais et allemand (suit la langue de macOS, menu *Langue*).
  Interface in het Engels, Frans, Nederlands en Duits (volgt de macOS-taal, menu *Taal*).
  Oberfläche auf Englisch, Französisch, Niederländisch und Deutsch (folgt der macOS-Sprache, Menü *Sprache*).
- Universal build (Apple Silicon + Intel), GitHub releases / Binaire universel, releases GitHub /
  Universele build, GitHub-releases / Universal Binary, GitHub-Releases.

### Changed / Modifié / Gewijzigd / Geändert
- Native login item replaces the Python LaunchAgent (migrated automatically).
  Élément de connexion natif à la place du LaunchAgent Python (migré automatiquement).
  Native inlogonderdeel in plaats van de Python-LaunchAgent (automatisch gemigreerd).
  Natives Anmeldeobjekt statt des Python-LaunchAgents (automatisch migriert).
- New bundle ID `io.github.alexandrebeauduin.MouseMover`: grant Accessibility again and
  re-enable launch at login.
  Nouveau bundle ID : redonne l'autorisation Accessibilité et réactive le lancement au démarrage.
  Nieuwe bundle ID: geef Toegankelijkheid opnieuw en zet openen bij inloggen weer aan.
  Neue Bundle ID: Bedienungshilfen erneut erlauben und Start bei der Anmeldung wieder aktivieren.
